# Bruno collection ของ sda-shop

เปิดด้วย Bruno extension ใน VS Code แล้วเลือก environment `local`

| โฟลเดอร์ | มีอะไร |
|---|---|
| `00 · ตัวอย่าง` | ลองกด Send ก่อน (ต้องรัน `make dev` อยู่) · `Health check` ได้ 200 · `Categories (ยังไม่มี)` ได้ 404 |
| `01 · หน้าร้าน` | เส้น 1–4 สินค้าแนะนำ หมวดหมู่ รายการสินค้า รายละเอียดสินค้า (public) |
| `02 · สมาชิก` | เส้น 5–7 สมัคร เข้าสู่ระบบ โปรไฟล์ |
| `03 · ตะกร้า` | เส้น 8–11 |
| `04 · คำสั่งซื้อ` | เส้น 12–14 |
| `05 · หลังร้าน` | เส้น 15–17 (admin) และตัวช่วยเข้าสู่ระบบ admin |

ทุก request มี

- body ตัวอย่างตามที่หน้าเว็บส่งจริง
- `assert` ของ status ที่ต้องได้เมื่อเขียนเสร็จ
- แท็บ **Docs** บอกรูปแบบ response และกรณี error

ตอนนี้ backend ยังไม่มีเส้นเหล่านี้ จึงได้ `404` และ assert เป็นสีแดง เราจะเขียนให้ผ่านในโมดูล 5

## ลำดับที่ควรกด

1. `05 · สมัครสมาชิก` (ครั้งเดียว ครั้งที่สองจะได้ 409)
2. `06 · เข้าสู่ระบบ` → script เก็บ token ไว้ในตัวแปร `token`
3. เส้นในโฟลเดอร์ `03` และ `04` ใช้ `token` นี้ · `12 · สั่งซื้อ` เก็บเลขไว้ใน `orderId`
4. หลังร้าน: ใส่ `adminPassword` ใน environment `local` (เป็นช่อง secret ไม่ถูกบันทึกลงไฟล์) แล้วกด `ตัวช่วย · เข้าสู่ระบบ admin`

อีเมลและรหัสผ่านของลูกค้าทดสอบอยู่ใน `environments/local.bru` ใช้ตอนพัฒนาบนเครื่องเท่านั้น
